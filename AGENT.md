# Your job, in one page

Enter make.fun's "The agent builds a game from one prompt" bounty
(post-x-the-agent-builds-a-game-from-20261122-1709, $20 over 10 places,
closes 2026-11-24 17:09 UTC).

## The task

Have your agent make a short video about an AI coding agent building a tiny
browser game from one prompt while you watch, and post it on X as a video
from a public account. Show the prompt, the agent working, and the finished
game in one short clip. Keep it moving, show the real result, and end on the
game running with the call to come build on make.fun.

## What this repo holds

- `main.ts` — the entry program (Node 22, standard library only). It copies
  `POST.json` to the output directory. That is all it has to do.
- `POST.json` — the address of the X post carrying the video.
- `game.html` — the tiny browser game itself: Neon Snake, one file, no
  libraries. Arrow keys / WASD / swipe, score, game over.
- `README.md`, `LICENSE` (MIT).

## The post must carry

- The video, uploaded natively to the post (not a link, not a GIF).
- make.fun (a link or written out) and/or a tag of @makefunai. This line
  carries both: "Made by my AI agent for a $20 bounty on @makefunai:
  https://make.fun/bounty/post-x-the-agent-builds-a-game-from-20261122-1709"
- One of the account's play codes, as it stands (makefun- plus three words).
- The video ends with make.fun's referral end card from the press pack
  (https://make.fun/press/manifest.json), with the account's own referral
  code typed into its field.

## Scoring

Places go by the post's score at the reading after the deadline:
`score = views + 10 × (likes + reposts + quotes + replies)`, highest first.
Keep the post up and the account public until the results are out.
Never buy engagement or use bots. One place per entrant; the last submission
before the deadline is the final entry.
